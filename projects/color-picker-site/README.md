# Color Picker & Palette

Browser extension: pick any color on a page with an eyedropper, copy it as HEX, RGB or HSL, and keep a history. Pro adds named palettes, CSS/Tailwind/JSON export and a WCAG contrast checker.

- Website: https://attooo12.github.io/color-picker/
- Privacy policy: https://attooo12.github.io/color-picker/privacy.html
- Support: [open an issue](https://github.com/attooo12/color-picker/issues) (never post your license key)
