Looking for a ColorZilla alternative?

ColorZilla is a large, established, free eyedropper extension. Here's exactly what it offers, what it asks for, and two lighter options: DevTools, and Color Picker & Palette. As of September 2026.

Not affiliated with ColorZilla; the name is used only to identify the product being compared.

1. ColorZilla, checked directly

Per its Chrome Web Store listing on September 24, 2026: version 4.1, built on Manifest V3, rated 4.6 out of 5 from about 3,900 ratings, with 4,000,000+ users — a much bigger install base than any of the tools on this page. It's free, and colorzilla.com's own Firefox listing says the developers intend to keep it that way ("the most sophisticated color tool on the market — for free").

Feature-wise it goes well beyond a plain eyedropper: an eyedropper that can sample at different zoom sizes, a Photoshop-style color picker, a CSS gradient generator, a whole-page palette extractor, picked-color history, several pre-installed palettes, and element info (tag, class, size) for developers. Some accessibility workflows use it to grab a hex value that's then pasted into a separate WCAG contrast tool like WebAIM's, since ColorZilla itself doesn't calculate a contrast ratio.

On permissions: ColorZilla's own Chrome Web Store listing includes a section explaining why it asks to "access data on all websites," stating this is needed for its core color-picking functionality and that "ColorZilla DOES NOT collect any of your data or your browsing activity on any websites." That's the developer's own account of what the broad permission is for; it's listed here as a factual difference from the other two options below, not a claim about what it actually does with that access.

2. The free built-in option: DevTools

Chrome, Edge and Firefox all have an eyedropper built into DevTools' Styles panel (see the full walkthrough). No install, no permissions beyond what your browser already has, and it opens straight from an element's color swatch. It doesn't keep a history across sessions, has no gradient tool and no whole-page palette extraction.

3. Color Picker & Palette (made by me)

Color Picker & Palette uses the browser's own built-in eyedropper API, copies HEX (with RGB and HSL shown), and keeps your last 12 picks plus a picker window for colors outside the browser tab. It has no host permissions and no content scripts: it only touches a page when you actively start a pick, and it makes no network requests. Free covers the eyedropper and history. Pro (€5 once, no subscription) adds OKLCH, unlimited named palettes with CSS/Tailwind/JSON export, and a WCAG AA/AAA contrast checker.

5. Where ColorZilla is better

It's dramatically more established: 4,000,000+ users and years of continuous development versus a brand-new, not-yet-listed extension. It has a gradient generator and whole-page palette extraction that neither DevTools nor Color Picker & Palette currently offer (both ColorZilla and Color Picker & Palette can also pick a color from outside the browser tab; DevTools can't). If you want one tool that covers color picking, gradients and page-wide palettes together, ColorZilla covers more ground.

6. Where Color Picker & Palette differs

The main difference is permissions and scope: Color Picker & Palette asks for no host permissions and runs no content script on pages you haven't actively picked from, using only the browser's built-in eyedropper API and making no network requests at all. It's a narrower tool — no gradients, no whole-page extraction — built around picking, organizing into named palettes, and a dedicated WCAG contrast checker in Pro. DevTools remains the zero-install option for a one-off pick.

FAQ

Is ColorZilla free?

Yes, per its own site and Chrome Web Store listing, with no premium tier found in its current description as of September 2026.

Why does ColorZilla ask for access to all websites?

Per ColorZilla's own Chrome Web Store listing, this is because its eyedropper needs to read pixel colors from any page you visit, and it states it does not collect your data or browsing activity. That's a broader permission than a tool using only the browser's built-in eyedropper API needs, which is a factual trade-off, not a claim about misuse.

Does ColorZilla check WCAG contrast ratios?

Not on its own. Common workflows use ColorZilla to grab a hex value and paste it into a separate contrast checker such as WebAIM's. Color Picker & Palette's Pro tier includes a built-in WCAG AA/AAA checker instead.

What's the truly free, no-install option?

Your browser's own DevTools eyedropper (Chrome, Edge, Firefox), reachable from any color swatch in the Styles panel. See the full walkthrough for all four free methods.
