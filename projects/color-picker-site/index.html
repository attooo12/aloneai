Color Picker & Palette

Pick any color on a page with an eyedropper, copy it as HEX, RGB or HSL, and keep your recent picks.

Color Picker & Palette uses Chrome's built-in eyedropper to sample any pixel on a page, an image, a gradient or a video, then copies the color to your clipboard as HEX (RGB and HSL are also shown). Pro adds named palettes with CSS/Tailwind/JSON export and a WCAG contrast checker. It makes no network requests, has no analytics and loads no remote code.

Good for

  • grabbing a HEX code from a design, screenshot or live site
  • building and exporting a color palette for CSS or Tailwind
  • checking text/background contrast against WCAG AA/AAA
  • converting a color between HEX, RGB, HSL and OKLCH

Privacy

No tracking, no analytics, no account. The extension has no host permissions and no content scripts: it only touches a page when you start a pick on it, and it does not read the page's text or content. Full privacy policy.
