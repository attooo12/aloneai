EditThisCookie is gone: what happened, and what to use instead

If you searched for EditThisCookie and landed here, read this before you install anything called that.

Short version: the original EditThisCookie extension was removed from the Chrome Web Store, and a lookalike using its name turned out to be malware. If you have a cookie extension installed that you haven't checked recently, check it now (section 2 below) before doing anything else.

1. What actually happened, with sources

EditThisCookie was a long-running, popular cookie editor for Chrome — several sources put it at over 3 million users and around 11,000 ratings at its peak. It ran on Manifest V2, the older Chrome extension platform that Google phased out through 2024. Reporting differs slightly on the exact trigger, but the outcome is agreed on:

  • The extension disappeared from the Chrome Web Store; gHacks (Dec 31, 2024) and TechSpot both link the removal to the Manifest V2 phase-out and note the original developer has said they sold the extension before the changes that led to its removal.
  • After the original vanished, a copycat listing appeared using the same name (first as "EditThisCookies", later "EditThisCookie®") and picked up tens of thousands of installs from people searching for the original. Security researchers found it was malware: obfuscated code, ad injection, phishing behaviour and the ability to steal data, particularly Facebook session data — see Cybersecurity News and GBHackers. Google later removed that copycat too.

Not affiliated with EditThisCookie; the name is used only to identify the product and explain what happened to it.

2. Check what you actually have installed

Open chrome://extensions and look at the name carefully:

  • If it's named "EditThisCookie®" or "EditThisCookies" (note the extra letter or the trademark symbol), or you don't remember installing it, remove it immediately — these names were used by the malicious copycat described above.
  • If it's the original "EditThisCookie" by editthiscookie.com, it's no longer available in the Chrome Web Store, which means it isn't receiving security updates through the store either way. An unmaintained extension with cookie access is worth replacing regardless of how it got installed.
  • Click Remove, not just "disable" — a disabled extension can sometimes be re-enabled by a bug or a bad update.

Chrome DevTools (built in, free)

Press F12 → Application → Storage → Cookies → pick the site. You get every cookie including HttpOnly and partitioned ones, and you can edit or delete rows directly. There's no dedicated "add extension" step and nothing to trust beyond the browser you already use. The trade-off: no popup shortcut, no export button, and you're looking at rows in a table rather than a simple editor UI.

Cookie-Editor (free, third party)

Cookie-Editor is a maintained, open-source Manifest V3 extension built specifically as a cookie popup editor, available for Chrome, Firefox, Edge, Safari and Opera. It's a reasonable, well-established choice if you just want the EditThisCookie-style popup back for free. I haven't reviewed its source line by line myself; check its listing and permissions before installing, same as with any extension.

FAQ

Is EditThisCookie safe to install today?

Not from the Chrome Web Store: the original listing is gone, and a version using its name was confirmed malicious and removed. Treat any "EditThisCookie" install offer outside the official (now-defunct) listing as suspicious, including standalone .crx files found on forums or mirror sites.

Why was EditThisCookie removed?

Reporting differs on the precise mechanism, but it coincides with Chrome's 2024 Manifest V2 phase-out and, according to some accounts, a change of maintainer account before removal. See the gHacks and TechSpot sources above for the detail each outlet was able to confirm.

What replaced EditThisCookie?

There's no official successor. Chrome's built-in DevTools Application panel covers the basics for free, and independent Manifest V3 cookie editors such as Cookie-Editor and Cookie Crate cover the popup-editor workflow EditThisCookie users are used to.

Can I trust a "EditThisCookie revival" I found on GitHub?

Be cautious. Cookie access lets an extension read your login sessions, so only install from a listing you can verify (Chrome Web Store review process, a known open-source maintainer with a public repo and history). A standalone .crx file with no build provenance is exactly the risk that hit the copycat listing.
