How to view and edit localStorage in Chrome

Whether you're debugging a "logged in but the UI thinks I'm not" bug or just want to poke at what a site stores, here's the built-in way, step by step, plus its rough edges.

1. Open the Application panel

Open DevTools (F12, or right-click the page → Inspect), then click the Application tab (if you don't see it, click the » overflow arrow to find it). In the left sidebar, under Storage, expand Local Storage and click the site's origin. You'll see a table of every key/value pair the page has stored, with a preview pane below showing the selected value in full.

2. Add a new entry

Double-click the empty area of the table below the existing rows. DevTools adds a new row and puts your cursor in the Key column; type the key, press Tab or Enter, then type the value.

3. Edit an existing entry

Double-click a cell in the Key or Value column to make it editable, change it, then press Enter (or click elsewhere) to commit it. Refresh the page afterward for the site's own script to pick up the new value — the edit is saved to storage immediately, but a page that already read the old value into memory won't notice the change until it re-reads it, which usually happens on reload.

4. Delete entries

Click a row to select it, then use the delete (trash) icon in the panel's toolbar to remove just that entry, or the Clear all icon next to it to wipe every key for that origin at once.

5. sessionStorage works the same way

Right below Local Storage in the same sidebar is Session Storage, organized and edited identically. The difference is scope: sessionStorage is cleared when the tab closes and isn't shared across tabs of the same site, while localStorage persists until something deletes it and is shared by every tab on that origin.

6. Or skip the table: use the Console

For a quick read or write without navigating the panel, the Console tab gives you plain JavaScript against whichever origin is currently the selected context:

localStorage.getItem('theme');           // read one key
localStorage.setItem('theme', 'dark');   // write one key
localStorage.removeItem('theme');        // delete one key
JSON.stringify(localStorage);            // dump everything as one string (simple, short values only)
Object.entries(localStorage);            // every key/value pair as an array

This is faster for a single value, but you're back to raw strings and no visual table, and (same as the panel) a change here doesn't retroactively update variables the page's own script already read into memory.

Where the built-in editor is clunky

It's a genuinely useful tool and it's free and already installed, but a few things are rough: values are edited as raw text with no JSON formatting or validation, so a stored JSON object is one long unreadable line until you copy it out; there's no search/filter box across keys; you have to reopen DevTools and re-navigate to Application → Local Storage → the right origin every time; and there's no export button if you want a copy of what's stored.
