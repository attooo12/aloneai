# Cookie Crate: Cookie & Storage Editor

Chrome MV3 extension by AloneAI. Popup editor for the current tab's cookies, localStorage and sessionStorage.
No service worker, no content scripts, no network requests, no remote code, no analytics.

## Files
- `popup.html/js/css`: cookies / storage / profiles views for the active tab (`?tabId=N` selects a tab; used by tests).
- `options.html/js`: plan, license key, Pro all-sites export/import, protected-cookie list, about.
- `cookielib.js`: pure logic (site matching, validation, JSON + Netscape cookies.txt import/export). Unit tested.
- `cookies.js`: chrome.cookies / permissions / scripting / storage operations, protection, profiles.
- `license.js` (PRODUCT `cookie-crate`, production public key), `config.js` (`CHECKOUT_URL = ''` => "Pro coming soon").

## Which cookies are "this site's"
Every cookie the browser could send to any page of the tab's host: host-only cookies of the host, domain cookies of
the host and of each parent domain (`.example.com`), all paths, Secure or not, and partitioned (CHIPS) cookies of
all partitions (`getAll({partitionKey: {}})`). Sibling subdomains and host-only cookies of the parent are excluded.
"Delete all" deletes exactly this set, minus protected cookies (Pro). `chrome.cookies.remove()` works by URL + name,
which can also remove a same-named cookie on a parent domain; `removeCookie()` snapshots and restores such collateral
deletions (tested).

## Permissions, and why activeTab is not enough
`cookies`, `storage`, `activeTab`, `scripting`; `optional_host_permissions: ["<all_urls>"]`.

- `activeTab` (granted when the user clicks the toolbar button) gives the popup the tab's URL and lets
  `chrome.scripting` read/write the tab's localStorage/sessionStorage.
- It does NOT give `chrome.cookies` access: the cookies API checks the extension's host permissions, and the
  temporary activeTab grant is a per-tab grant that it does not consult. Verified in the e2e test for the "no host
  permission" state: a page on c.example sets a cookie, and `chrome.cookies.getAll({url})` from the extension
  returns nothing. (What could not be verified headlessly: an actual toolbar click, so the "activeTab doesn't cover
  cookies" statement rests on Chromium's design plus that test, not on a real click.)
- So the popup shows "Allow access to this site" and requests only `*://<host>/*` plus its parent domains up to the
  registrable domain (parent-domain cookies need their own host permission). No full Public Suffix List is bundled:
  a small list of two-label suffixes (co.uk, com.au, ...) plus the rule "generic label (co/com/org/ac/...) under a
  two-letter TLD" avoids asking for e.g. `co.uk` or `co.th`, and under hosting platforms (github.io, herokuapp.com,
  amazonaws.com, ...) only the exact host is requested. An unlisted multi-label suffix (e.g. `kyoto.jp`) would still
  be asked for; Chrome never stores cookies on public suffixes, so that request grants nothing useful but is harmless.
- Pro "all sites" export/import requests `<all_urls>` at click time, with an explanation on the page.
- Known Chrome behaviour: on some platforms the popup closes while Chrome shows its permission prompt. The grant
  still happens; click the icon again.

## Tests
```
node test/unit.mjs   # 61 checks, pure logic
node test/e2e.mjs    # 67 checks, real extension in headless Chromium
```
e2e loads a test copy: TEST ONLY public key; `*://*.test/*` granted up front and `ALL_SITES` narrowed to it (a
permission prompt can't be clicked headlessly); `tabs` added to stand in for the activeTab URL grant of a toolbar
click. Pages are served on a.test, sub.a.test, other.a.test, b.test, c.example via `--host-resolver-rules`.
`test/TEST_ONLY_private_key.pem` is gitignored and regenerated by `keygen.mjs` if missing.

Not covered by automated tests: the real permission prompt / toolbar click, incognito cookie stores (the code picks
the tab's store via `getAllCookieStores`), the popup "Choose file…" button on platforms where the file dialog closes
the popup (pasting always works; the options page has a file import for all sites).
