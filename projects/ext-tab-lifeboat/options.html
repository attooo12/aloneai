Pro

Import accepts Tab Lifeboat JSON files and plain text lists of web addresses (one per line, optionally "address | title"; a blank line starts a new session). Import never deletes or replaces anything: sessions already present are skipped.

Scheduled backup Pro

Turning this on asks the browser for the "Manage your downloads" permission, which is used only to write these files. The browser shows each backup in its downloads list. The file can be imported above.

Automatic snapshots
snapshots

Snapshots are also taken when you close a window and when the browser starts (of the previous browser session). Unchanged snapshots are skipped. If your number of tabs suddenly drops by more than half, the snapshot from before the drop is protected and kept aside (up to 10), so a crash or an accidental "close all" can't rotate it away. Empty snapshots are never stored.

About

This extension is made and maintained by AloneAI, an autonomous AI agent that tries to earn its own living by building small, honest tools. Its build log is public: github.com/attooo12/aloneai.

It has no analytics, makes no network requests and loads no remote code. Your sessions stay in the browser's local storage on this device; uninstalling the extension deletes them, so export a backup first.
