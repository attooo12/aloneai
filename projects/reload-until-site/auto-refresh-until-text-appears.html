How to auto refresh a page until a word appears

For appointment slots, restocks, exam results and status pages: reload the page on a timer, stop when the text shows up, and get alerted.

You want to keep pressing F5 until a page says "Available", "In stock" or "Results published". Most auto-refresh tools only reload the page. They don't look at what's on it. Below are three ways to do it properly, from most to least do-it-yourself. All three only watch a page. Buying or booking is still up to you.

Be polite to the site. Reload no more often than you really need to (every 30 to 60 seconds is plenty for most pages), and check the site's terms. Some ticket and booking sites forbid automated access or block clients that reload too fast.

1. A userscript (free, any browser)

Install a userscript manager such as Tampermonkey or Violentmonkey, create a new script, and paste in the code below. Change @match to the page you want to watch, and TEXT to the words you are waiting for.

// ==UserScript==
// @name   Reload until text appears
// @match  https://example.com/the/page*
// @grant  none
// ==/UserScript==
(() => {
  const TEXT = 'In stock';   // what you are waiting for (case-sensitive)
  const EVERY = 60;          // seconds between reloads
  const SETTLE = 3;          // seconds to let the page finish loading its content
  setTimeout(() => {
    if (document.body.innerText.includes(TEXT)) {
      document.title = 'FOUND: ' + document.title;
      alert('Found "' + TEXT + '"');
    } else {
      setTimeout(() => location.reload(), (EVERY - SETTLE) * 1000);
    }
  }, SETTLE * 1000);
})();

To wait for a text to disappear (for example "Sold out"), change the check to !document.body.innerText.includes(TEXT).

Limits: the script stops working if the page logs you out or shows an error page, because the @match no longer applies or the text never appears. The alert() only gets your attention if the tab is visible. If the page loads its content slowly, raise SETTLE. Chrome also requires you to allow userscripts for the manager: turn on developer mode on the extensions page, or use the manager's "Allow user scripts" toggle.

2. A small Python script (free, for simple pages)

If the text is in the page's HTML itself, you can check it without a browser. This works for many status and results pages. It doesn't work for pages that build their content with JavaScript, or for pages that need you to be logged in.

import time, urllib.request

URL = "https://example.com/the/page"
TEXT = "In stock"
EVERY = 60  # seconds

while True:
    req = urllib.request.Request(URL, headers={"User-Agent": "Mozilla/5.0"})
    html = urllib.request.urlopen(req, timeout=30).read().decode("utf-8", "replace")
    if TEXT in html:
        print("\aFound:", TEXT)
        break
    print(time.strftime("%H:%M:%S"), "not yet")
    time.sleep(EVERY)

Quick test: open the page, press Ctrl+U (view source) and search for your text. If it's there, the script will see it.

3. An extension that reloads and checks the text

If you'd rather not write code, or you need it to work on pages behind a login, use an extension that runs inside your normal browser tab:

  • Reload Until (made by me, see below). Pick an interval and a text, choose "appears" or "disappears", and it reloads until the condition is met, then sends a desktop notification, plays a sound and brings the tab to the front. It stops if the tab navigates to another site. Free for one tab. Pro (€9 once, no subscription) adds more tabs at once, regular expressions and checking only part of the page.
  • Page-change monitors such as Distill Web Monitor check pages in the background or in the cloud and alert you when something changes. They are a good fit if you want to watch many pages over days and don't need a tab open.
  • Plain auto-refreshers reload on a timer but don't check the page for you, so you still have to keep looking at it.

Tips that save you trouble

  • Choose a text that only appears in the state you want. "Available" might also appear in "Not available". A button label ("Book now") or a unique phrase is safer. Or wait for "No appointments" to disappear instead.
  • Stay logged in. If the site logs you out after a while, every method above just keeps reloading the login page. Browser-based methods (1 and 3) use your existing session.
  • Keep the computer awake. A laptop that goes to sleep stops reloading.
  • Add a little randomness (a few seconds of jitter) if you watch a page for hours. It's gentler on the server.
