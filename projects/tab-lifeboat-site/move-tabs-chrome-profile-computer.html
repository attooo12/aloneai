Move your tabs to a new Chrome profile or computer

Getting a new laptop, setting up a second profile, or handing a machine to a colleague? Here's what actually moves, and what doesn't, for each method.

"Tabs" and "bookmarks" are different things to Chrome, and most of the built-in tools move one and not the other. Read the limitation in each section before you close your old browser.

1. Same Google account: turn on Chrome Sync

If both the old and new profile/computer sign in with the same Google account, this is the easiest option and needs no file at all:

  • On the old computer: Settings → you should see your account at the top with sync on. Check chrome://settings/syncSetup and make sure Bookmarks is toggled on; turn on Tabs too if you want your currently open tabs visible on the other device.
  • On the new computer or profile: sign in with the same Google account and turn sync on the same way. Give it a minute to finish syncing.

Once it's on, bookmarks and saved tab groups appear on both devices and stay in sync automatically going forward — unlike a one-time export, future changes carry over too. Your currently open tabs (not bookmarked, not grouped) show up as a clickable list at chrome://history/syncedTabs on the new device, one at a time; that's a list to reopen from, not a restored window with pinned tabs and layout intact.

2. Different account, or a one-time move: export/import bookmarks as HTML

This works regardless of which Google accounts are involved, or if the new profile has no account at all:

  1. On the old profile: open the Bookmark Manager (Ctrl+Shift+O, Mac Cmd+Option+B), click the three-dot menu at top right, choose Export bookmarks, and save the HTML file somewhere reachable from the new machine (a USB drive, cloud storage, email to yourself).
  2. On the new profile: open Bookmark Manager, three-dot menu → Import bookmarks, and pick that file.

If your bookmarks bar on the new profile is empty, the imported bookmarks land right on it; if it already has bookmarks, Chrome puts them in a separate "Imported" folder instead. Same caveat as method 1: this moves bookmarks, not your open tabs, pinned status or tab groups. If you want to carry a specific set of open tabs this way, first bookmark them with Ctrl+Shift+D (see saving all open tabs), then export just that folder.

3. What actually carries pinned tabs and tab groups: a session file

Neither of the above preserves the things that make a window feel like your window: which tabs were pinned, which were grouped and in what color, and the order across multiple windows. Chrome doesn't have a built-in export for that. This is what Tab Lifeboat, which I make, is for: save the current window or all windows as a session (pinned tabs and tab groups included), then Settings → Export all to write a single JSON file. Copy that file to the new computer or profile by any means you like — it doesn't need a Google account or an internet connection at either end — install the extension there, and use Settings → Import a file… to bring it in. Import never deletes or overwrites anything already there; sessions that already exist are skipped.

This is local-only and doesn't touch your bookmarks at all, so it's a good complement to method 1 or 2 rather than a replacement: use Sync or bookmark export for your saved bookmarks, and a session file for the exact tabs you had open. It's free for up to 10 saved sessions; Pro (€5 once) adds unlimited sessions and export as Markdown or HTML in case you'd rather move a simple link list.

4. Advanced and last resort: copying the whole profile folder

Chrome stores an entire profile — bookmarks, history, cookies, extensions, saved sessions — in a folder on disk (for example ...\Google\Chrome\User Data\Default on Windows, or a numbered Profile 1, Profile 2 folder for additional profiles). In principle, closing Chrome completely and copying that whole folder to the same path on another computer moves everything at once, including things sync doesn't cover.

Treat this as a last resort, not a routine method: it's not an officially supported migration path, it can behave unpredictably if the Chrome versions differ significantly between the two machines, it carries over your saved passwords and cookies (which is a security consideration if the new machine isn't private to you), and any mistake while Chrome is still running on either side can corrupt the profile. If you do it, copy to a new empty profile slot rather than overwriting one that already has data you care about, and keep the original folder until you've confirmed the copy works.
