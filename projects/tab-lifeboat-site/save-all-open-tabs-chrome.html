How to save all your open tabs in Chrome

You've got 40 tabs open and you need to close the window, switch computers, or just tidy up without losing anything. Here are your options, from a built-in shortcut to a full session backup.

Note the difference between "save" and "back up." A bookmark or a saved tab group lives inside your Chrome profile. If you never lose that profile, that's fine. If you want a copy that survives a wiped profile, a new computer, or "I don't sync this browser," you need a file on disk, covered in section 4.

1. Bookmark all tabs: quick, built in, one-off

Press Ctrl+Shift+D (Mac: Cmd+Shift+D). Chrome asks for a folder name and where to put it, then bookmarks every open tab in the current window in one go. You can also get here by right-clicking empty space on the tab strip and choosing Bookmark all tabs, or from the Chrome menu (⋮) → Bookmarks (some versions show it under a "Bookmarks and lists" menu).

This is the fastest way to archive a finished project's tabs and it costs nothing. The trade-off: a bookmark folder is a flat list of addresses. Pinned status, the order across multiple windows, and native tab groups don't survive the round trip — reopening the folder gives you plain tabs in whatever order the bookmarks are in, not the window you had.

2. Save a tab group: keeps the name and color, syncs

If your tabs are already organized into a Chrome tab group (or you group them first: select tabs, right-click → Add tabs to new group, give it a name and color), right-click the group's name label and turn on Save group. Chrome then keeps that group even after you close it — it reappears under the browser's tab-group list (and, on the bookmarks bar in some Chrome versions) so you can reopen it later. If you're signed in with sync on, a saved group also shows up on your other signed-in devices.

This preserves the name and color that "Bookmark all tabs" throws away, but it's still a Chrome-internal object: there's no export button, no file you can move to a computer that isn't signed into the same account, and it only covers tabs you put in a group in the first place, not a whole messy window.

3. Turn on "Continue where you left off": a safety net, not a save

Settings → On startup → Continue where you left off. This makes Chrome reopen your tabs automatically after you quit and relaunch it. It's not something you trigger to "save" a particular set of tabs, and it won't help if you close a window on purpose, use "Clear browsing data," or move to a different computer — but it's worth having on regardless, since it also softens the blow of a crash. (For actually lost tabs after a crash or accidental close, see Chrome closed all my tabs: how to get them back.)

4. A session-saving extension: exact windows, tab groups and pinned tabs, exportable

None of the built-in options above give you a file you can back up, move between computers, or restore to the exact window layout you had — pinned tabs, multiple windows and tab groups included.
